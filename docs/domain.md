# 领域约定

白玉蟹联合品控结算链围绕养殖塘口、质量批次与农户结算保存可核对的业务记录。外部主体使用不含真实身份信息的稳定引用编号，时间采用带偏移量的 ISO 8601 字符串，材料只保存受控引用和 `sha256` 摘要。

交换事件包含 `event_id`、`subject_ref`、`occurred_at`、`source_sequence` 和 `payload_digest`。来源序号只在同一来源内递增，接收方必须保留原始发生时间，不得用到达时间覆盖。示例内容仅用于说明字段形状，不代表真实人员、机构或业务结论。

## 主线对象

- **养殖户 farmer**：与龙头企业签约的农户，帮扶档位影响结算加价。
- **塘口 pond**：养殖水体，归属养殖户；冻结期间禁止投苗与起捕。
- **合同 contract / contract_price**：按版本保存各等级单价与帮扶加价（分/公斤），版本登记后不改写，调价升版本。
- **苗种批次 seedling_batch → 投放 stocking**：企业统一供苗，投放扣减余量，Σ投放 ≤ 批次总量。
- **投入品 input_record / 技术指导 guidance**：按塘口记录，材料仅存受控引用与摘要。
- **捕捞批次 harvest_batch → 分级批次 grade_lot**：起捕生成批次，分级拆分必须满足 Σ分级重量 = 起捕毛重；批次可继续拆分为订单分配，可用量随分配扣减，全程守恒可溯。
- **抽检 inspection**：五重检测（round 1..5），可作用于塘口、捕捞批次或分级批次；不合格只冻结相关水体与关联批次。
- **冻结 freeze / 处置 freeze_action**：复检由检测员（inspector）、解封由质量经理（quality_manager）、销毁由销毁专员（destruction_officer）签署；解封必须先有合格复检，销毁仅适用于批次。
- **出口订单 export_order / 分配 export_allocation / 交付回执 delivery_receipt**：柜量折算为需求总量，质量条件为可接受等级集合；分配在同一事务内扣减订单额度与批次可用量，并发不超卖；回执实收数量为结算重量依据。
- **结算 settlement / settlement_line**：按交付时间匹配合同版本，金额 = 实收重量 ×（单价 + 帮扶加价）；结算单生成后不改写，退货以负金额冲正行追加并指向原行。

## 数量与金额

重量一律整数克，金额一律整数分；金额计算四舍五入到分。每次变更写入 `domain_event`，保留原始发生时间与内容摘要。
